## What Changed

Tier 2 narrative feature (`src/narrative/client.ts`) was calling Claude Opus 5 ($5/$25 per 1M tokens) to restate already-computed decision facts in Spanish (bounded restatement per proposal Deviation D7, not synthesis). This change swapped the call to Claude Haiku 4.5 ($1/$5 per 1M tokens, ~5x cheaper), which required reworking the call shape (not a drop-in swap):

- `src/narrative/client.ts`: `MODEL` changed to `'claude-haiku-4-5'`; removed `output_config: { effort: 'low' }` and `thinking: { type: 'adaptive' }` entirely (both unsupported on Haiku 4.5, would error if sent); `MAX_TOKENS` unchanged at 4096; doc comments rewritten to explain the cost-reduction goal, Haiku 4.5's lack of effort/adaptive-thinking support, and the bounded-restatement task framing.
- `tests/narrative/client.test.ts`: rewrote the `streamNarrative — call shape` test's pinned assertion (~lines 110-129) to expect the new call shape with no `thinking`/`output_config` keys.
- `openspec/specs/decision-narrative/spec.md`: ADDED one `[MANUAL-VERIFICATION-ONLY]` requirement/scenario gating this change from archiving PASS until a human confirmed Haiku 4.5 narrative quality against the Opus 5 baseline — same pattern as `n8n-cadence-6h`'s live-schedule gate and `n8n-fetch-klines-item-fix`'s live-execution gate.
- New `design.md` documented the `thinking`-param decision, explicitly superseding the archived Opus-5+adaptive-thinking rationale in `openspec/changes/archive/2026-08-17-dashboard-ux/design.md` (left unedited as audit trail, per design.md's own "Supersedes" note).

**Code delivery**: Already committed and pushed to `main` as commit `c3b436f` prior to this archive phase. This archive phase performs documentation/spec-closure only — no code was re-applied or re-committed here.
